## SSTI1 (PicoCTF, Web Exploitation, Easy)

For this picoCTF challege, I was given a website that echoed everything I entered into a text field. I entered {{7*7}}, and it echoed 49, meaning the backened was likely Jinja2/Python. From there, I wanted to list the files in the current directory so I used the standard `lipsum` payload for Jinja2 servers to run the `ls` command: `{{ lipsum.__globals__['os'].popen('ls').read() }}`. I soon found out that the flag was in the current directory, so I used the same payload to cat the flag and beat the challenge. I think the hardest part of this challenge for me was figuring out it was a Jinja2 backend and that you use `{{ }}` to tell the Jinja2 template engine to actually run your python code and not treat it as a string. This helped me understand the importance of sanitizing user input and forbidding the user access to Python objects and Remote Code Execution.
