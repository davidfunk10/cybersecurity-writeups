## Compiled (TryHackMe, Easy)

For this room, I started by running the `strings` command on the binary file `Compiled.Compiled`. This way, I would be able to see all the readable strings in the file and have information to work with. I noticed Compiled.Compiled was a compiled C binary that used a `scanf` function to read an inputted password. I also saw two other important strings from the output of the `strings` command. One had a `%s` inside it, indicating that it was a template string and that I should replace it and everything after it with the other standalone string. After combining these two strings, I got the flag. The main difficulty of this problem was understanding how the binary ran and how it used the `scanf` function without being able to run the binary directly.
